# springboot-shopping-cart
A production-ready backend application built using Java Spring Boot, Spring Security, JWT Authentication, MySQL, and Spring Data JPA.  
This project implements core e-commerce features such as user authentication, product management, cart operations, and order processing using clean, scalable backend architecture.

## 🚀 Features
- User Registration & Login (JWT Authentication)
- Role-based access using Spring Security
- Product Management (CRUD)
- Shopping Cart (Add, Update, Remove Items)
- Order Placement & Validation Workflow
- MySQL Integration using Spring Data JPA & Hibernate
- Global Exception Handling & Input Validations
- REST API Testing using Postman

## 🛠 Tech Stack
- Java  
- Spring Boot  
- Spring Security  
- JWT  
- MySQL  
- Spring Data JPA  
- REST APIs  
- Maven
